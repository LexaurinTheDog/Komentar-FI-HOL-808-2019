Kommentaari kattaa **127 kommentoitavaa yksikköä** — lain kaikki pykälät 1–127 § — **4 kommentaarin luvussa**; kunkin pykälän kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö, ajantasaistettu **27.3.2026** (lähteen metatiedot: voimassa, voimaantulo 1.1.2020).
